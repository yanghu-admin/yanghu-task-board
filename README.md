## 二、当前存在的问题

| 问题 | 说明 |
|------|------|
| 1. 照片容量不够 | 金数据免费版 100MB/月，几张照片就满了 |
| 2. 你仍需转发 | 经办人反馈消息需要你转发给 Marvis，无法完全自动化 |
| 3. 无任务编号选择 | 金数据表单没有任务编号下拉，需在备注里写 |
| 4. GitHub Actions 未启用 | token 缺少 workflow 权限，自动化处理无法部署 |
| 5. 图床未配置 | 图片直接存在 GitHub 仓库，大文件可能影响性能 |

## 四、当前完整工作流

```
你发任务：
  养护群里发"K12+300 护栏坏了 @张三"[照片]
    → 转发给 Marvis
    → Marvis 写 data.json + 存照片 + git push
    → 看板自动更新 ✅

经办人看任务：
  点群公告链接 → 看板页面（看到自己被分配的任务）

经办人反馈（目前方案）：
  方式A（推荐）：群里发"TASK-001 修好了"[照片]
    → 你转发给 Marvis
    → Marvis 更新 data.json + 存照片 + git push
    → 看板更新
  方式B（备选）：点金数据表单链接 → 上传照片+写备注
    → 你去金数据后台看到 → 转发给我/Marvis 更新

核验：
  黄瑾文/你点看板链接 → 点任务上的核验按钮 → 提交
```
